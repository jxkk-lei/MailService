# MailService

Консольный сервис для управления пользовательскими рассылками. Проект демонстрирует модульную организацию Python-приложения, объектно-ориентированную модель и сохранение данных в JSON.

## Возможности

- создание пользователей;
- создание списков рассылки с указанием автора;
- подписка пользователей на списки рассылки;
- проверка повторных подписок;
- создание сообщения для списка и подсчёт подписчиков;
- просмотр сохранённых пользователей, списков, подписок и сообщений;
- загрузка и сохранение данных в JSON;
- автоматизированные тесты `pytest`.

## Структура

- `models/` — классы `User`, `MailingList`, `Subscription`, `Message`;
- `services/mailing_service.py` — бизнес-логика в классе `MailService`;
- `storage/json_storage.py` — сериализация и восстановление объектов из JSON;
- `data/mailservice.json` — файл данных;
- `tests/` — автоматизированные тесты;
- `main.py` — точка входа.

## Запуск

```bash
python3 -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

## Проверка

```bash
python -m pytest
python -m flake8
```

## Формат хранения

В JSON сохраняются простые значения и идентификаторы связанных объектов. При загрузке сначала создаются пользователи, затем списки рассылки, подписки и сообщения. Связи восстанавливаются по идентификаторам.

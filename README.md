# MailService

MailService — учебный проект сервиса создания и управления пользовательскими рассылками. Проект разработан на Python и использует JSON-файл для хранения данных. Для веб-интерфейса применяется Django.

## Возможности

- Хранение данных пользователей.
- Создание и хранение списков рассылок.
- Связывание списков рассылок с их владельцами.
- Хранение сообщений, относящихся к спискам рассылок.
- Хранение подписок пользователей на списки рассылок.
- Сохранение и загрузка данных из JSON.
- Просмотр пользователей, списков рассылок, сообщений и подписок через веб-интерфейс Django.

## Технологии

- **Python** — основная логика приложения.
- **Django** — веб-интерфейс.
- **JSON** — хранение данных.
- **pytest** — автоматическое тестирование.

## Формат данных

Данные хранятся в файле `data/mailservice.json`.

Основные сущности:

| Сущность | Поля |
|---|---|
| Пользователь (`users`) | `id`, `name` |
| Список рассылки (`mailing_lists`) | `id`, `name`, `owner_id` |
| Подписка (`subscriptions`) | `user_id`, `list_id` |
| Сообщение (`messages`) | `id`, `list_id`, `text`, `date` |

Связи между сущностями задаются идентификаторами. Например, `owner_id` указывает на владельца списка рассылки, а `list_id` связывает подписки и сообщения с соответствующим списком.

## Установка

Требуется установленный Python и доступ к командной строке.

Клонируйте репозиторий и перейдите в каталог проекта:

```bash
git clone <URL-репозитория>
cd MailService
```

Создайте виртуальное окружение:

```bash
python3 -m venv venv
```

Активируйте его на macOS или Linux:

```bash
source venv/bin/activate
```

Установите зависимости:

```bash
python3 -m pip install -r requirements.txt
```

## Запуск консольной версии

Для запуска консольной версии используйте:

```bash
python3 main.py
```

## Запуск веб-интерфейса

Проверьте конфигурацию Django:

```bash
python3 manage.py check
```

Примените миграции Django:

```bash
python3 manage.py migrate
```

Запустите локальный сервер разработки:

```bash
python3 manage.py runserver
```

Веб-интерфейс будет доступен по адресу:

`http://127.0.0.1:8000/`

Основные страницы:

| Адрес | Назначение |
|---|---|
| `/` | Главная страница |
| `/users/` | Пользователи |
| `/lists/` | Списки рассылок |
| `/messages/` | Сообщения |
| `/subscriptions/` | Подписки |

Веб-интерфейс предназначен для локальной разработки. Перед развёртыванием в production необходимо настроить безопасность, секретные параметры, статические файлы и сервер приложения.

## Тестирование

Для запуска тестов используется `pytest`:

```bash
python3 -m pytest
```

## Разработка

Перед внесением изменений рекомендуется:

1. Активировать виртуальное окружение.
2. Установить зависимости из `requirements.txt`.
3. Запустить тесты.
4. Проверить Django-компоненты командой `python3 manage.py check`.
5. Проверить изменения перед созданием коммита.

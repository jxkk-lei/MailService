# MailFlow

## Назначение

**MailFlow** — сервис для создания и управления пользовательскими рассылками. Система позволяет пользователям создавать списки получателей, формировать сообщения и управлять подписками на рассылки.

## Целевая аудитория

Проект предназначен для:

* пользователей, которые хотят получать интересующую их информацию;
* авторов и владельцев рассылок;
* небольших организаций и сообществ, которым необходимо отправлять сообщения группам подписчиков.

## Описание предметной области

Сервис рассылок обеспечивает взаимодействие между авторами сообщений и их получателями.

## Основные сущности

* **Пользователь (User)** — зарегистрированный пользователь системы.
* **Список (List)** — список подписчиков, используемый для организации рассылок.
* **Сообщение (Message)** — текстовое содержимое, предназначенное для отправки подписчикам.
* **Подписка (Subscription)** — связь между пользователем и списком рассылки.

## Основные функции

* регистрация и управление пользователями;
* создание и редактирование списков рассылок;
* добавление и удаление подписчиков;
* создание и редактирование сообщений;
* подписка пользователя на список;
* отмена подписки;
* просмотр доступных списков;
* отправка сообщений подписчикам.

## План развития проекта

1. Реализовать базовую модель пользователей, списков, сообщений и подписок.
2. Добавить регистрацию и авторизацию пользователей.
3. Реализовать создание и управление списками рассылок.
4. Реализовать механизм подписки и отмены подписки.
5. Добавить создание и отправку сообщений.
6. Добавить историю отправленных сообщений.
7. Реализовать планирование рассылок на определённое время.
8. Добавить статистику отправок и активности подписчиков.
9. Добавить веб-интерфейс для управления рассылками.
10. Реализовать уведомления о новых сообщениях.

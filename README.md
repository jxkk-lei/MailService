# MailService

## Назначение

MailService — сервис для создания и управления пользовательскими рассылками. Приложение позволяет создавать списки рассылок, формировать сообщения и отправлять их подписчикам.

## Целевая аудитория

Предполагаемые пользователи приложения:

* авторы и владельцы рассылок;
* небольшие организации и сообщества;
* пользователи, желающие получать информацию по интересующим их темам.

## Предметная область

Предметная область проекта связана с созданием и распространением информационных сообщений среди групп пользователей.

## Основные сущности

* **User** — пользователь системы.
* **MailingList** — список получателей рассылки.
* **Message** — сообщение, отправляемое подписчикам.
* **Subscription** — подписка пользователя на список рассылки.

## Основные функции

* создание списка рассылки;
* создание и отправка сообщений;
* подписка пользователя на рассылку;
* отмена подписки;
* управление списками рассылок.
